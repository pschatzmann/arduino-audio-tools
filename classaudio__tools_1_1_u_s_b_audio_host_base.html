Detailed Description

USB Audio Class (UAC1 and UAC2) host: reads PCM audio from an attached USB microphone and/or writes PCM audio to an attached USB speaker or headset, using the same API as the USB Audio device (USBAudioStream).

Directions (the RxTxMode is used the same way as for the device):

  • RX_MODE: readBytes() provides the audio of the attached microphone (isochronous IN endpoint of the device, config.enable_ep_in)
  • TX_MODE: write() sends audio to the attached speaker (isochronous OUT endpoint of the device, config.enable_ep_out)
  • RXTX_MODE: both, e.g. for a headset

The requested sample_rate, channels and bits_per_sample are matched against the alternate settings of the attached device. When the device can not provide the requested format and config.host_apply_device_format is true, the closest format is used, stored in the configuration and reported to the subscribed listeners (setAudioInfo()). In RXTX_MODE the format of the RX stream is reported; use audioInfoTx() for the TX format.

setVolume() and setMute() are forwarded to the Feature Unit of the attached device (all active directions); setAudioInfo() with a new sample rate re-negotiates the streams. When config.volume_active is true, the volume is in addition applied in software.

This class implements the USB stack independent UAC logic: the stack calls are delegated to a USBAudioHostBackend.

Note
Use the USBAudioHostStream type alias instead of this class.
