Detailed Description

Arduino Stream which is using the RadioHead library to send and receive data. We use the driver API directly.

In TX_MODE the written data is collected and sent in messages of maxMessageLength() bytes: call flush() to send a partially filled message. In RX_MODE each received message is buffered, so that it can be read in chunks of any size.

Note
Supported only on Arduino platforms with support for the RadioHead library and the related hardware (e.g. ESP32 with LoRa, nRF24L01, etc.)!
Requires: 👉 https://www.airspayce.com/mikem/arduino/RadioHead/
