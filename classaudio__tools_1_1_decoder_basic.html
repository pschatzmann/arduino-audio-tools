Detailed Description

DecoderBasic - supports mime type audio/basic Requires https://github.com/pschatzmann/codec-g7xx The content of the "audio/basic" subtype is single channel audio encoded using 8bit ISDN mu-law [PCM] at a sample rate of 8000 Hz.
