Detailed Description

An AudioSource that uses the SMBClient of the https://github.com/pschatzmann/TinySMB library to retrieve the files from a Windows, macOS, Samba or NAS share. You need to provide an SMBClient object to the constructor and make sure that you call begin() on it before you access the files.

The directory is scanned recursively and the files that match the extension are played in the order in which the server lists them. The file names are not stored: the share is listed each time a new file is selected, so only the name of the actual file is kept in memory.
