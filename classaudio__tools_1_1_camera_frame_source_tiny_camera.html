Detailed Description

VideoFrameSource that pulls frames from a camera via TinyCamera (https://github.com/pschatzmann/TinyCamera) - so it works on every platform TinyCamera supports (ESP32 via esp32-camera, ESP32-P4 MIPI-CSI via ESP_Video, RP2040, STM32, desktop). nextFrame() returns the buffer of a freshly captured frame, returning the previous one to the driver first; as with any VideoFrameSource, the returned pointer is only valid until the next nextFrame() call.

begin() captures one probe frame to determine width/height/format, so videoInfo() is complete right after it (as VideoMuxer::begin() requires) without any frame_size lookup table. Only the frame rate has to be given, since a camera has no fixed one: use the rate you actually want to capture (and encode) at.
