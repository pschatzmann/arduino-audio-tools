Detailed Description

template<class SDT, class FileT>
class audio_tools::SDDirect< SDT, FileT >

We access the files directy with an index. The index is determined by a recurseve tree walk thru the directory. Unfortunately the SDTFAT library has it's own API which is incompatible with the SD API.
