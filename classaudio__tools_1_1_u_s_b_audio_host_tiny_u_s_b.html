Detailed Description

USB Audio host for the Adafruit TinyUSB host stack: reads audio from an attached USB microphone and/or writes audio to an attached USB speaker.

The USB stack is driven by the application: readBytes() and write() call serviceUSB(), which runs tuh_task(). Call serviceUSB() regularly (e.g. in loop()) if you neither read nor write.

Board settings

  • RP2040/RP2350 (arduino-pico): USB Stack "Adafruit TinyUSB Host (native)"
  • Pico-PIO-USB or MAX3421E: set up the Adafruit_USBH_Host in your sketch and pass it to the constructor; set config.host_rhport accordingly.
Note
I recommend to use the USBAudioHostStream type alias instead of this class directly, so that the code is portable to other platforms.
