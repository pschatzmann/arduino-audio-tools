Detailed Description

Common functionality of the BLE serial server and client: data is exchanged via two characteristics like a serial connection. The audio info can optionally be exchanged via a third characteristic.

  • setFramed(true) keeps the original write sizes (e.g. for encoded frames): each write() is transmitted as a separate BLE packet and readBytes() provides one packet at a time.
  • setAudioInfoActive(true) informs the other side about changes of the audio info.
