Detailed Description

Ogg Vorbis Decoder.

This class wraps VorbisDecoder in an Ogg container decoder, allowing decoding of Ogg Vorbis streams with automatic packet extraction.

Usage:

  1. Instantiate OggVorbisDecoder.
  2. Feed Ogg Vorbis data to the decoder.
  3. PCM output is provided via the underlying VorbisDecoder.
