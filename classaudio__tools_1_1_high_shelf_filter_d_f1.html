Detailed Description

template<typename T = float>
class audio_tools::HighShelfFilterDF1< T >

Second-order high-shelf filter (BiQuad DF1). Same coefficients as HighShelfFilter. NOTE: unlike the other DF1 filters here, this is NOT a working fix for q1_14_t (or similar bounded fixed-point types) – see the.

Template Parameters
noteon HighShelfFilter for measured numbers. Watch for the LOGE warning from checkCoeffRange() in begin().
Parameters
frequencyshelf transition frequency in Hz
sampleRatesample rate in Hz
gainboost/cut in dB (positive = boost, negative = cut)
slopeshelf slope (default 1.0; values < 1.0 give a gentler slope)
