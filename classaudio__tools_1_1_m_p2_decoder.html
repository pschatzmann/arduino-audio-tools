Detailed Description

Decoder for MPEG-1 Layer II (MP2) audio using the TinyMP2 library. Compressed data provided via write() does not need to be aligned on frame boundaries: bytes are accumulated internally and decoded frame by frame; any invalid/garbage bytes are skipped automatically (resync).

Depends on https://github.com/pschatzmann/TinyMP2
