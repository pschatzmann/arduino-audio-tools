Detailed Description

Default implementation for a Channel. You can provide the Sound Generator as parameter to the effects: e.g. DefaultSynthesizerChannel<AudioEffects<SineGenerator<int16_t>>> *channel = new DefaultSynthesizerChannel<AudioEffects<SineGenerator<int16_t>>>();.
