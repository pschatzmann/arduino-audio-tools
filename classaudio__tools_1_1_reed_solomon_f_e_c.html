Detailed Description

template<int bytecount, int additional_bytes>
class audio_tools::ReedSolomonFEC< bytecount, additional_bytes >

Forward error correction using Reed-Solomon: write is encoding and readBytes does the decoding.

The written data is split into blocks of bytecount bytes and each block is written with additional_bytes parity bytes. Data is only sent in complete blocks: the bytes of a trailing incomplete block (less than bytecount bytes) are never written. The reader collects the encoded blocks from the stream and corrects up to additional_bytes / 2 wrong bytes per block. If a block can not be corrected, the uncorrected data bytes are provided and failedBlocks() is incremented. There are no sync markers: if bytes get lost on the link, the block boundaries are wrong until begin() is called on both sides to restart at a block boundary.
