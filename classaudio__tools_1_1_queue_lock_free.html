Detailed Description

template<typename T>
class audio_tools::QueueLockFree< T >

Lock-free MPMC queue.

T must be move-constructible and move-assignable (or copy-assignable as a fallback, since dequeue() assigns the result out via std::move); default-constructibility is NOT required (element storage is raw bytes — no T object is created until enqueue).
