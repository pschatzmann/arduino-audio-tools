Detailed Description

ESP32 Virtual File System for the SPFFS. The default mount point is "/spiffs" DRAFT implementation: not tested See https://github.com/espressif/esp-idf/tree/master/examples/storage/sd_card/sdspi.

Note
Supported only by ESP32 (Arduino and IDF)
