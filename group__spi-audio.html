◆ SPIRegAudioRegister

enum SPIRegAudioRegister : uint8_t

Register map shared by SPIRegAudioMaster and SPIRegAudioSlave.

Wire protocol (compatible with the TinySPISlave RegisterMap):

  • command byte: bit7 = read, bits 0..6 = register address
  • write frame: [cmd][bytes...] (CS low .. CS high)
  • read request: [cmd|0x80][n] (n = number of bytes wanted)
  • read reply: a second frame in which the master clocks n bytes (0x00) while the slave shifts out the register content. A short pause (CS high) is required between the two frames.

Address 0 is reserved: the dummy bytes clocked by the master during the reply frame are ignored by the slave.

All multi byte values are little endian.
