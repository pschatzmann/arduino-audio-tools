class  MJPEGDecoder
 Motion-JPEG video decoder: wraps TinyJPEGDecoder (https://github.com/pschatzmann/TinyJPEG, a header-only port of ChaN's TJpgDec) as a VideoDecoder, so it can be plugged directly into e.g. DemuxerAVI::setOutputVideo()/DemuxerMP4::setOutputVideo() - the same role H264Decoder (CodecH264.h) and MPGDecoder (CodecMPG.h) play for their own codecs. Named "MJPEGDecoder" rather than reusing TinyJPEGDecoder's own name to avoid shadowing that class from within this one. More...
 
class  MJPEGEncoder
 Motion-JPEG video encoder: wraps TinyJPEGEncoder (https://github.com/pschatzmann/TinyJPEG) as a VideoEncoder - the MJPEG counterpart of H264Encoder (CodecH264.h), e.g. for VideoMuxer/ VideoMuxerWithTasks with a camera that delivers raw pictures. Configure it via setSize()/setVideoFormat() (RGB565 - the default -, RGB888 or RGB666, packed) and optionally setQuality()/setSubsample(), then feed raw pictures via write(): each one is encoded into one complete JPEG image, which is written to the target configured via setOutput() in a single write() call - as the muxers expect one frame per call.
