Detailed Description

Stream for reading and writing audio data using the WM8960 Codec Chip You need to install https://github.com/pschatzmann/arduino-wm8960.

Author
Phil Schatzmann
Copyright
GPLv3
Note
Supported only on Arduino platforms with the WM8960 library. For a Platform independent implementation use the I2SCodecStream with the audio-driver-library!
