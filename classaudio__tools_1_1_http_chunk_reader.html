◆ waitAndConsume()

void waitAndConsume ( Client & client,
char expected )
inlineprotected

Waits (bounded by a short timeout) for the next byte to arrive and, if it matches expected, consumes it - logs (but does not throw) if a different byte or no byte at all shows up, since that means the stream is already desynced and readChunkLen() right after this will detect and report it.
