Detailed Description

ATRAC decoder (ATRAC1, ATRAC3, ATRAC3+ and ATRAC9) which converts the raw ATRAC frames into 16 bit PCM data. This class depends on https://github.com/pschatzmann/codec-atrac which is based on the ATRAC decoders of FFmpeg.

The decoder needs to know the stream parameters which are usually found in the header of a container: register one decoder per type with WAVDecoder::addDecoder() to process WAV files (.at3, .at9), use ContainerATRACOMA or ContainerATRACAEA (see ContainerATRAC.h) for OMA and AEA files, or call begin(type, sampleRate, channels, blockAlign, extradata, extradataSize) yourself if you get the raw frames from somewhere else. The write() method can be called with any amount of data: the frames of blockAlign bytes are assembled internally.

Type blockAlign extradata
ATRAC1 212 * channels -
ATRAC3 frame size 10, 12 or 14 bytes
ATRAC3PLUS frame size -
ATRAC9 frame size (or 0: derived) 12 bytes (rate and channels)

Phil Schatzmann
