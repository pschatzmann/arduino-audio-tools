Detailed Description

USBAudioHostBackend for the ESP-IDF usb_host library which is part of arduino-esp32 (ESP32-S2, ESP32-S3 and ESP32-P4).

begin() installs the USB host library (unless it was already installed, e.g. by another library) and starts a task which processes the library events. The client events and transfer completions are processed by task(), which is called continuously by the USB task of USBAudioHostESP32.

Isochronous endpoints are streamed with two transfers in flight, each covering kPacketsPerTransfer service intervals.
