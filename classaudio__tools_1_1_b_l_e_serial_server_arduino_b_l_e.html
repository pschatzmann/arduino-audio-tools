Detailed Description

A BLE server that implements a serial protocol, so that it can be used to send and receive audio. In BLE terminology this is a Peripheral. This implementation uses the ArduinoBLE library.

The data is exchanged with the client when BLE.poll() is called: this is done automatically in readBytes(), available(), write() and availableForWrite().
