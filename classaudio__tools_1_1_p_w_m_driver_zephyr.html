Detailed Description

Audio output to PWM pins for Zephyr RTOS.

Author
Phil Schatzmann
Copyright
GPLv3

Supports PWM audio output on Zephyr targets using the native PWM driver API. Manages multiple PWM channels with configurable frequency and resolution.

Characteristics:

  • Uses Zephyr's PWM driver API (pwm_set_dt, pwm_get_cycles_per_sec)
  • Supports multiple channels via channel configuration
  • Callback-based playback using AudioTimer
  • Automatic pin management
