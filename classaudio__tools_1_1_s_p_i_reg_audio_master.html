Detailed Description

SPI master which streams audio to a SPIRegAudioSlave (based on the TinySPISlave library) using its register map: it defines the AudioInfo and the mime type and writes the audio data according to the space which is reported by the available-space register.

SPIRegAudioMaster master;
auto cfg = SPIRegAudioMasterConfig();
cfg.sample_rate = 44100; cfg.channels = 2; cfg.bits_per_sample = 16;
master.begin(cfg);
master.setMime("audio/pcm");
master.write(data, len);
