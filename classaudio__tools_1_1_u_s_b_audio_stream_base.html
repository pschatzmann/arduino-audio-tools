Detailed Description

Role-independent front end shared by USB Audio devices (USBAudioDeviceBase, aliased as USBAudioStream) and USB Audio hosts (USBAudioHostBase, aliased as USBAudioHostStream).

It provides the identical public Arduino stream API for both roles: write() sends audio to the USB peer, readBytes() receives audio from it, plus volume/mute state, callbacks and the one-shot RX startup prime. The USB stack specific parts are provided by the subclasses via the pure virtual methods.
