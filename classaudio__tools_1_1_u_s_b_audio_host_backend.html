Detailed Description

Abstract seam for every raw USB host stack call the UAC host class logic (USBAudioHostBase) needs. Concrete subclasses wrap TinyUSB host (USBAudioHostBackendTinyUSB) or the ESP-IDF usb_host library (USBAudioHostBackendESP32).

Control requests are asynchronous: the result is reported via USBAudioHostEvents::onControlComplete(), which may also be called before control()/setInterface() returns. Only one control request is in flight at any time. Streaming endpoints are kept running by the backend itself (resubmitting transfers) once openStream() was called.
