Detailed Description

template<typename T = float>
class audio_tools::LowPassFilterDF1< T >

Second-order low-pass filter (BiQuad DF1). Same coefficients as LowPassFilter, but built on BiQuadDF1, whose separate x[]/y[] delay lines stay bounded to the actual signal range – unlike DF2's single delay line, which can need far more dynamic range than the signal for low cutoff/ sampleRate ratios. Use this (not LowPassFilter) when T is a bounded fixed-point type like q1_14_t.

Parameters
frequencycutoff frequency in Hz
sampleRatesample rate in Hz
qquality factor (default 0.7071 = Butterworth, no resonance peak)
