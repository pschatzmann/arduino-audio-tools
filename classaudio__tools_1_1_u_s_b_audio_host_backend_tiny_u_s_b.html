Detailed Description

USBAudioHostBackend for the TinyUSB host stack provided by the Adafruit TinyUSB Library (RP2040/RP2350 native or Pico-PIO-USB, ESP32-S2/ S3/P4 native OTG, STM32, or a MAX3421E host controller on any platform).

TinyUSB does not provide a host side Audio class driver, so this backend registers its own usbh_class_driver_t via usbh_app_driver_get_cb() (only one application host driver can be registered by a sketch).

The isochronous transfers are resubmitted at most once per USB frame: some host controller drivers (e.g. the RP2040 native one) do not schedule isochronous transfers per frame, so this keeps the packet rate at the nominal 1 kHz.

Note
TinyUSB reads the whole configuration descriptor into a buffer of CFG_TUH_ENUMERATION_BUFSIZE bytes (256 in the Adafruit library): devices with a larger configuration descriptor (e.g. many headsets) are rejected by the enumeration. Increase this value in the tusb_config_<mcu>.h of the Adafruit TinyUSB Library if your device is not detected.
