Detailed Description

AAC Decoder (LC, HE-AAC, MAIN, LTP) using faad2: https://github.com/pschatzmann/codec-faad2 Supports ADTS, ADIF and raw AAC. This needs a big stack and you need to make sure that memory is allocated on PSRAM.
