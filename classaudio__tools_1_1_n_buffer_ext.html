◆ resize() [2/2]

template<typename T = uint8_t>
virtual bool resize ( size_t  size,
int  count 
)
inlinevirtualinherited

Resize the buffers by defining a new buffer size and buffer count. If the block size changes, existing blocks can't be reused, so all buffered data is discarded (with a warning). If only the count changes, existing blocks and their data are kept: buffers are just allocated or freed to reach the new count.
