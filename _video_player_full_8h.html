class  VideoPlayerFull
 VideoPlayer subclass configured for every container format and codec this library ships a portable software demuxer/decoder for - video AND audio - so it's the "just point it at a file, any common format just works" player, the same convenience MultiVideoDemuxerFull/ MultiVideoDecoderFull/DecoderHelix each provide on their own side. Use this instead of the base VideoPlayer unless you specifically want to keep this class's extra dependencies (below) out of your build - the base VideoPlayer's demuxer and video/audio multi-decoders all start empty (see its own class comment), so it has none.
