Detailed Description

template<typename CalcT = int16_t>
class audio_tools::AudioFixedFFT< CalcT >

AudioFFT using the fixedpoint-fft library. CalcT selects the calculation type (default int16_t, see FFTDriverFixedFFT); pick int8_t on RAM-constrained plain AVR targets, or float/double on FPU-equipped targets.

◆ toMEL()

float * toMEL ( int n_bins,
float min_freq = 0.0f,
float max_freq = 0.0f,
bool power = false )
inlineinherited

Convert the FFT result to MEL spectrum. The triangular filterbank uses fractional (HTK style) weights, so no filter collapses to zero width, and it is computed once and cached until the parameters change.

Parameters
n_binsnumber of mel bands (<= 0: size())
min_freqlower edge in Hz (<= 0: frequency(0))
max_frequpper edge in Hz (<= 0: frequency(size() - 1))
poweruse the power spectrum |X|^2 instead of the magnitude |X|
