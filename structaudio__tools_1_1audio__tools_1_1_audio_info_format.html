Detailed Description

AudioInfo extended with a WAVEFORMATEX-style codec tag (the "wav code"): identifies the codec (PCM, AAC, ALAC, ...) - AudioFormat::UNKNOWN if not determined. mime() derives the corresponding mime type from format - not a separately stored field, so it can never go stale.

Not merged directly into AudioInfo because AudioInfo is treated as a raw, byte-serializable struct in some places (e.g. AudioLoRa, ContainerOgg, ContainerBinary, the BLE sandbox client); adding fields there changes that wire layout for all of them. Returned by DemuxerAVI/DemuxerMP4's getAudioInfo(), mirroring the existing WAVAudioInfo : AudioInfo pattern (CodecWAV.h) used for WAV header parsing/writing.
