Detailed Description

template<typename Platform>
class audio_tools::RTSPServer< Platform >

RTSPServer - Audio Streaming Server (task-based)

This class extends RTSPServerBase to add task/thread management for handling RTSP sessions. It schedules the main server loop and individual session loops as tasks, so that the server does not block the main loop on platforms that support threading (e.g., ESP32 with FreeRTOS).

Usage:

  • Construct with a valid RTSPMediaStreamer and port number.
  • Call begin() to start the server and listen for clients.
  • Optionally set a session path callback for custom session handling.

Only one client is served at a time: further clients are accepted when the active session has ended.

Inherits all protocol, session, and connection logic from RTSPServerBase. Only task scheduling and concurrency logic is implemented here.
